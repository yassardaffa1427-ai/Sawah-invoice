❓ Pertanyaan Umum

Bagaimana cara membuat invoice baru? ▼

Buka halaman /invoice-edit, lalu isi detail invoice, pembeli, item, diskon, dan pajak.

Apakah data invoice otomatis tersimpan? ▼

Tidak, data hanya tersimpan selama tab browser terbuka. Untuk menyimpan, gunakan fitur Cetak PDF atau Export Excel.

Bagaimana cara menyimpan invoice sebagai PDF? ▼

1. Klik tombol "Cetak PDF" di aplikasi

2. Di dialog cetak browser, pilih "Save as PDF"

3. Pilih lokasi folder dan klik Save

Apakah aplikasi ini offline-ready? ▼

Ya, 100% berjalan di browser tanpa memerlukan server backend tambahan.
